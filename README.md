# 双面号码布批量生成器

这个仓库从 2026 年接力长城校园赛的制作脚本整理而来。运行时按**学校／组别／队伍**保存每位选手的双页 PDF，并生成清单和运行报告。仓库含程序、标题字体与程序绘制的无标志演示模板；**不包含真实报名名单、赛事标志、正式模板或历史成品**。第三方字体不受本仓库代码的 MIT 许可证覆盖，见 `fonts/README.md`。

## 先运行匿名示例

需要 Python 3.10 或更新版本。在 macOS／Linux 终端：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python 生成号码布.py
.venv/bin/python test_demo.py
```

Windows PowerShell：

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python 生成号码布.py
.venv\Scripts\python test_demo.py
```

不带 `--input` 时，程序使用三条虚构记录和随仓标题字体，自动绘制男子组棕色、女子组深蓝色、混合组青色的演示模板。输出写入 `output/时间戳/学校/组别/队伍/姓名.pdf`。演示名单每组只有一人，因此“队伍不是 5 人”的提醒是预期结果。演示模板和输出均不可作为正式赛事印刷稿。

## 使用自己的名单

Excel 活动工作表第一行必须含有以下六列，列顺序可以不同：

| 序号 | 组别 | 组队名称 | 学生姓名 | 性别 | 学生所属学院名称 |
| --- | --- | --- | --- | --- | --- |
| 1 | 男子组 | 示例队 | 张三 | 男 | 示例大学 |

组别只接受 `男子组`、`女子组`、`混合组`。男子组必须标 `男`，女子组必须标 `女`；混合组成员按名单原样处理。把自己的 Excel 放到被 `.gitignore` 忽略的 `data/` 目录后运行：

```sh
.venv/bin/python 生成号码布.py \
  --input data/报名名单.xlsx
```

仓库中的优设标题黑覆盖许多常用汉字；遇到它不包含的字符时，使用 `--fallback-font 路径` 指定另一款 TTF，也可用 `--title-font 路径` 更换标题字体。缺字会记入 `生成清单.csv`，程序以非零状态结束。不要仅凭程序退出状态决定是否送印，仍要检查 PDF 正反两页、姓名、学校和颜色。

## 使用本次比赛的模板

只有在确认有权使用和分发相关素材后，才能决定是否把赛事模板和标志公开。若只在自己的电脑上制作，把三份原 PDF 放在被忽略的 `private_assets/` 目录，并传入目录和正式名单：

```sh
.venv/bin/python 生成号码布.py \
  --input data/报名名单.xlsx \
  --templates-dir private_assets \
  --fallback-font private_assets/备用字体.ttf \
  --kun-glyph private_assets/堃_同款字形.png
```

模板目录内的文件名须为：

- `校园赛号码布_男子组_官方.pdf`
- `校园赛号码布_女子组_自制深蓝.pdf`
- `校园赛号码布_混合组_自制青色.pdf`

这一路径只兼容本次比赛模板的双页结构、占位文字和 PDF 文字对象顺序；不能保证任意 PDF 都可替换。女子组深蓝 `#33617E` 和混合组青色 `#218899` 是本次比赛自制配色，后续可调整；男子组棕色 `#944523` 来自原模板。若模板颜色更改，还要同步修改脚本中的 `school_color`。姓名含“堃”时必须传入本次定稿字形。

脚本只负责个人双页 PDF、`生成清单.csv` 和 `运行结果.txt`。学校分类文件夹自动生成；厂商 ZIP 和人工核对大图目前仍需另行制作。任何记录失败都会使程序返回失败状态，详情以清单为准。

## 公开仓库与赛事素材

代码按仓库根目录的 MIT 许可证发布。随仓字体的作者与来源单独标记在 `fonts/README.md`；赛事模板和 Logo 不在仓库内。真实名单、成品和个人素材请放在被忽略的 `data/`、`private_assets/` 或 `output/`，不要提交到公开仓库。

当前脚本的正式模板按组别固定选择。同一场赛事的各参赛学校共用**承办学校与其跑团**的底部标志；若换一所学校承办，就应为该场赛事替换承办学校、跑团及合作方标志，再提供对应的三份组别模板，并核对脚本中的模板文件名、文字位置和学校文字颜色。不要把南科大赛事的固定标志原样用于别的学校。
